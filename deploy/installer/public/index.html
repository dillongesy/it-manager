Confirm it's your server

Enter the setup code that install.sh printed when it finished. It proves you manage this server, so nobody else on the network can set it up first.

Lost it? On the server, in the install folder, run docker compose logs installer.

Network

Computers on this network can open the Portal at . Everyone else is refused. Written as a network range: 192.168.1.0/24 covers 192.168.1.1 to 192.168.1.254. Separate several ranges with commas, for example to add a VPN. Detected for this server: .

Only if your office DNS has a name for this server, such as portal.office.lan. The Portal's certificate is issued for these names and for the server's IP address, so the browser accepts either. Leave empty to use the IP address only. This is not where staff use the Field App; that is set up later in Nginx Proxy Manager with your public domain.

.0.0 – .8.255

The app's containers talk to each other on nine private networks inside this server. They must not overlap any network the server already uses (your LAN, a VPN, other Docker apps). The suggested value is free; change it only if you know it collides with a network elsewhere.

Security and updates

Firewall

This applies only to the app's ports; other services on this server are not changed. After setup it can be changed only on the server: sudo ./install.sh firewall on|off.
